The central problem

Planning when the world refuses to stay still.

Finding a route through a fixed grid is one problem. Keeping that route useful when an obstacle appears after the robot has already started moving is a more interesting one.

How can an autonomous agent update its path efficiently when its environment changes?

The project compares ordinary pathfinding with dynamic replanning, measuring how much work each approach repeats when conditions change.

Hardest part

Dynamic obstacles.

The biggest challenge is making the robot react intelligently while moving, without simply throwing away all previous search work and starting over every time.

What I’m building

A small system with a clear experiment.

The simulator is intentionally simplified so the project can focus on the AI itself: search behavior, heuristics, replanning, and measurable differences between approaches.

01

Algorithms

Three ways to think about the route.

Dijkstra gives a non-heuristic baseline. A* adds informed search. D* Lite is the stretch goal for reusing information after the environment changes.

Baseline

Dijkstra

Explores outward based on known path cost without a goal-directed heuristic.

What I want to learn

Questions that turn the demo into research.

The end goal is not just a robot that reaches the destination. It is understanding why one search strategy behaves differently from another.

How much does a heuristic reduce unnecessary exploration compared with uninformed search?
What changes when an agent must replan after the environment has already changed?
When is recalculating A* from scratch acceptable, and when does incremental planning become useful?
How do path length, explored nodes, runtime, and replanning cost change across different maps?

I want to explore pathfinding for an autonomous robot in a changing environment. I’m planning to build a simple warehouse simulation where the robot has to reach a destination while avoiding obstacles, and compare algorithms like A* and Dijkstra, and possibly D* Lite for replanning.

The hardest part for me will probably be handling dynamic obstacles efficiently, because the robot may need to change its path while it is already moving. That is also the main problem I want to learn from: how search algorithms behave when the environment is constantly changing, and how autonomous systems can replan without starting everything from scratch.
